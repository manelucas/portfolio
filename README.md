# Portfolio

Personal portfolio built with React, Vite and Bootstrap.

## Scripts

- `yarn start` – dev server at http://localhost:3000
- `yarn build` – production build into `dist/`
- `yarn preview` – serve the production build locally
- `yarn deploy` – build and publish to GitHub Pages

Pushing to `main` also deploys to Vercel (settings in `vercel.json`).

## Adding a project

Add the screenshot to `src/assets`, then import it and add an entry in `src/data/projects.js`.

## Colours

The palette is defined as CSS variables at the top of `src/App.css`.
